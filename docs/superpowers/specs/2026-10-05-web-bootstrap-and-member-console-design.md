# Web 首次设置与成员节点管理

状态：首次设置与成员节点管理方案已获用户确认。本文描述拟实现的行为，当前镜像尚未包含这些功能。

## 目标与名称

把部署中的角色选择、本机中继注册、成员节点入群／退群和日常本机配置放到网页中完成。
界面统一称 **主控**、**成员节点**、**集群**、**Tailnet**。
OAuth 提示只写 `devices:core:read`。

用户已经选择：成员节点使用本机独立的管理员账号，与主控失联时仍能登录和管理。
主控继续使用现有管理员账号；普通平台账号不获得服务器本机管理权限。

## 首次使用流程

1. 打开服务器的 HTTPS 管理页；没有本机管理员时先设置用户名、密码和确认密码。
2. 登录后，尚未完成角色设置的实例显示两个入口：**配置为主控**、**加入已有集群**。
3. 配置为主控：确认本机域名、TLS 和中继监听配置，完成后进入现有集群管理界面。
4. 加入已有集群：进入成员节点界面，填写主控 HTTPS 地址和一次性注册码，在网页上提交注册。
5. 管理员可以先保存成员节点配置、稍后再注册；未注册时管理页持续可用，中继不放行设备。

注册码由资源所有者在主控网页创建服务器后取得；既有私钥证明、HTTPS 域名证明和一次性限制继续适用。
注册失败时页面显示失败阶段，可以重试；已提交的注册请求使用现有持久化 receipt／pending 流程。

## 主控界面

保留现有 Tailnet、资源、授权、账号、DERP map 与观测页面，增加管理员可见的本机设置入口。
本机设置提供 **注册本机中继**：填写显示名称、域名和公开端口，创建资源并完成本机注册，
不再要求复制注册码到密码文件或运行 `node enroll`。注册本机中继是显式操作，资源的使用授权仍走既有规则。

## 成员节点界面

成员节点只管理本机，提供：

- 主控地址、集群与节点标识、注册状态、最近联系时间。
- 收到／应用的策略版本、中继可用状态及本机流量观测。
- 加入集群、退出集群、本机设置和本机管理员密码修改。
- 带宽规则：总预算、owner／shared 权重、shared 上限，以及各 Tailnet 的权重与上限。

成员节点不提供主控的平台账号、Tailnet OAuth 或共享授权管理接口。
本机登录和修改设置不依赖主控在线，也不依赖 Tailnet API。

成员节点的带宽规则由主控保存，经现有控制流下发；面板分别显示主控配置与本机应用状态。
本机管理员通过该节点自己的有效会话调整本节点规则，不获得其他节点或 Tailnet 的管理权限。
规则调整不改变设备许可、授权关系或许可截止时间；主控失联时可查看本机状态，规则保存显示不可用。
本机预算上限单独保留，主控预算超过本机上限时明确显示现有策略拒绝状态。

退出集群先停止控制连接和本机转发，关闭既有中继连接，再清理旧注册会话及所属策略缓存／watermark。
节点私钥和本机管理员保留。退出后进入未加入状态，可填写新主控与注册码；重启不能恢复旧集群许可。
在线退出时向主控释放本机实例，主控撤销旧节点会话及既有使用授权，将资源转为待重新注册。
失联时允许完成本机退出，旧会话在主控侧仍按原期限失效。
同一集群重新加入时，资源所有者通过主控网页重新签发与资源绑定的注册码，
继续验证原节点私钥及 HTTPS 域名；旧授权不会自动恢复。

## 网页配置范围

网页提供本机公网域名、公开 DERP／STUN 端口、实际监听端口、TLS 模式、证书方式、
手动证书／私钥上传、节点预算上限和日志等级。主控的身份／联系保留期沿用现有设置页。
密码、注册码和私钥不进入 URL、日志或普通配置读取响应。

配置复用现有校验和原子写入。页面区分已保存配置和正在运行的配置；需要重启的修改通过
“保存并应用”完成相应服务重启，并显示应用结果。普通配置更新不更换节点身份或已有主控数据库。

容器端口发布、DNS、云防火墙和外部反代属于宿主机部署设置，需要部署时准备好。
首次网页入口使用已配置的 HTTPS；当前服务器沿用现有 external TLS 反代。
运行目录、数据库路径和管理 socket 等部署路径继续由启动配置确定。

## 启动和权限边界

首次设置、主控、未加入成员、已加入成员分别是明确的持久状态。
管理 HTTP 服务必须先于角色业务可用；角色确定之前不启动主控身份同步或允许中继数据转发。
同一管理入口根据本机状态显示向导、主控页面或成员节点页面。

复用现有账号密码、受保护会话和 CSRF 机制；成员节点的账号存储在本机独立数据中。
本机配置、注册、退群和服务重启只允许本机管理员调用。主控的平台普通账号、
远端节点会话和其他服务器的管理员会话均不能操作本机。
角色选择和配置应用与控制连接的启停串行执行；管理服务独立于控制连接保持可用。

现有 main/member 启动分支、成员地址必填校验以及仅提供 domain challenge 的成员 HTTP handler
需要调整为上述状态；新网页调用直接复用现有注册、配置校验和策略应用代码。
不扩大 DERP 数据协议、设备许可或跨 Tailnet 共享权限。

## 现有部署

已有管理员的主控直接进入现有管理界面；新增本机设置入口，不重建账号或资源。
已注册成员保留主控地址、节点私钥、注册记录和策略期限，只首次补设本机管理员。
已有 YAML 和本地命令继续有效，手工预配置实例按其现有角色启动。
已有业务数据的主控不提供一键改为成员节点的操作；首次角色选择只针对尚未配置的实例。

## 验收

- 空数据目录：首次管理员设置、两个角色分支、重启后状态与账号保持。
- 主控：原管理流程可用，网页注册本机中继仍进行真实域名和私钥验证。
- 成员：网页入群成功、失败重试、独立登录、失联时本机管理可用。
- 退群：在线和失联两种情况立即停止本机转发；重启和重新入群不能复用旧许可。
- 权限：匿名、普通平台账号、远端节点会话和跨站请求不能修改本机状态。
- 设置：字段校验、原子保存、应用／重启结果及已有数据保留。
- 当前服务器的主控数据原地升级；成员流程使用独立测试实例，保留生产 multiderp 条目。
